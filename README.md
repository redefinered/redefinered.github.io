# Edward De Guzman — Portfolio

Personal portfolio site for [redefinered.github.io](https://redefinered.github.io).

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Framer Motion
- Design language ported from [Astrologic Labs](https://github.com/redefinered/astrologiclabs)

## Development

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` deploy automatically via GitHub Actions to GitHub Pages.
